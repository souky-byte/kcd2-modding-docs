# kcd-toolkit

- **GitHub**: https://github.com/altire-dev/kcd-toolkit
- **Language**: C# (.NET)
- **Stars**: ~10+
- **Last Updated**: Active (2025)
- **Purpose**: Collection of KCD2 modding tools and utilities

## Description
A centralized toolkit providing multiple tools for KCD2 modding: PAK building, mod scaffolding, asset extraction, and a combined mod suite.

## Included Tools
| Tool | Description |
|------|-------------|
| KCD PAK Builder | Turns directories into game-ready PAK files |
| KCD Mod Generator | Builds file/folder structure for new mods |
| KCD Asset Finder | Searches/extracts assets from KCD2 PAK files |
| KCD Mod Suite | Combined application suite |
| KCD Core | Core library for KCD2 modding |

## Modding Patterns
1. **Mod Scaffolding**: Auto-generates correct folder structure
2. **PAK Building**: Automated .pak creation from mod directories
3. **Asset Extraction**: Reverse lookup into game PAK files
4. **Community Tooling**: Modular, contribution-friendly architecture
