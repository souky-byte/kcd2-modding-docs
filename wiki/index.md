# Modding Kingdom Come: Deliverance 2

> Source: [https://youtrack.warhorsestudios.cz/articles/KM-A-0](https://youtrack.warhorsestudios.cz/articles/KM-A-0)

This wiki is a documentation for modding for the game Kingdom Come: Deliverance 2.

* If you are a consumer of mods looking for how to install mods, see [Installing Mods](installing-mods.md)
* If you are a modder, start by looking at [Technical Overview](technical-overview/index.md)

This youtrack server is not intended for customer support or reporting bugs with the actual game. For that use [Kingdom Come: Deliverance II Player Support](https://support.plaion.com/en/games/kingdomcome2/)

**Comments policy**: Comments on this wiki are enabled; however, they are not intended to be used as a public forum or customer support. Please use comments as notes to article authors. For help with your specific problems or general discussion, try the [official discord server](https://discord.com/invite/rRRJse5), [unofficial modding discord server](https://discord.com/invite/NxXznywRXh), or social media.
